# Smart-Recipe-Preparation-Agent

## Project Overview

The Smart Recipe Preparation Agent is an AI-powered cooking assistant developed using IBM Watsonx Orchestrate and IBM Granite Models.

The agent helps users prepare meals using the ingredients they already have. It retrieves relevant recipes from a recipe knowledge base and generates personalized recipe suggestions, cooking instructions, ingredient substitutions, cooking tips, and dietary adjustments.

The solution uses Retrieval-Augmented Generation (RAG) to provide accurate and context-aware recipe recommendations.

---

## Problem Statement

Many users struggle to decide what meals they can prepare with the ingredients available at home. Recipe information is often scattered across different sources, making meal preparation time-consuming and inefficient.

The Recipe Preparation Agent solves this problem by retrieving relevant recipes and generating personalized cooking guidance based on available ingredients, dietary preferences, and food restrictions.

---

## Objectives

- Suggest recipes using available ingredients.
- Retrieve relevant recipes from a knowledge base.
- Generate step-by-step cooking instructions.
- Provide ingredient substitutions.
- Offer cooking tips.
- Support dietary preferences and food restrictions.
- Reduce food waste and save time.

## Role of Agentic AI

Agentic AI enables the system to function as an intelligent cooking assistant. The agent retrieves recipes, understands user requirements, and generates personalized recommendations using IBM Granite and Watsonx Orchestrate.

The system autonomously performs retrieval, reasoning, and response generation to provide practical and context-aware cooking assistance.
